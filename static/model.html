The model (src/marsupials.f90) talks to SQLite through a small ISO_C_BINDING wrapper (src/sqlite_db.f90). Create the database, tables, and content ahead of time; the app opens it read-only.

User input is always passed as a bound parameter, never concatenated into SQL, and every statement and connection is released before returning:

call db_open_readonly('marsupials.sqlite3', db, ok, errmsg)
call db_prepare(db, 'SELECT name, latinName FROM marsupials ' // &
                'WHERE instr(lower(name), lower(?1)) > 0', stmt, ok)
if (ok) call stmt_bind_text(stmt, 1, query, ok)

do while (ok)
  call stmt_step(stmt, has_row, ok)
  if (.not. (ok .and. has_row)) exit
  name = stmt_column_text(stmt, 1)
  latin_name = stmt_column_text(stmt, 2)
end do

call stmt_finalize(stmt)
call db_close(db)
