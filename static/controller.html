The controller is written in Fortran itself, in src/app.f90. Each route renders HTML into content, which is wrapped in the shared layout and returned in a response_t:

select case (path)
case ('/html')
  content = '<div class="container"><h1>Hello World</h1></div>'
  ok = .true.

case ('/')
  call jade_render_file('template/index.jade', content, ok)

case ('/healthz')
  res%content_type = 'text/plain; charset=utf-8'
  res%body = 'ok'
  return

case default
  res%status = 404
  content = '<h1>Page not found!</h1>'
  ok = .true.
end select

GET query strings and URL-encoded POST bodies are both available through get_param:

case ('/search')
  call search_page(get_param(req, 'q'), content, ok)

In searches the controller gets input from the model and URL variables, and displays it in the view. Anything echoed back is escaped with html_escape:

call find_marsupial(query, found, item, ok)
if (found) then
  call render_result(item, result, ok)   ! template/result.jade with key_value_t vars
else
  result = '<p>No results for &quot;' // html_escape(query) // '&quot;</p>'
end if
