The controller is written in Fortran itself, in handle_request in src/app.f90. Each route appends HTML to a growable string_buffer and sets the response status:

select case (req%path)
case ('/')
  call append_template(ctx, page, 'index.jade', ok, res)
case ('/hello')
  call page%append('<h1>Hello, ' // html_escape(params%get('name', 'world')) // '!</h1>')
  ok = .true.
case default
  res%status = 404
  res%body = error_page(res%status)
  return
end select

A search route gets input from the URL, asks the model, and renders a template per result:

call find_marsupials(ctx%db, params%get('q'), found, ok)
do i = 1, size(found)
  call vars%set('name', found(i)%name)
  call vars%set('latinName', found(i)%latin_name)
  call page%append(render_source(result_template, vars))
end do
