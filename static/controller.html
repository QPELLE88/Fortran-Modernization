The controller is plain Fortran in src/app.f90. handle_request receives a parsed request_t and returns a response_t (status, content type, body), so it can be unit tested without a web server.

select case (req%path)
case ('/')
  resp = static_page(cfg, 'index.jade')
case ('/search')
  resp = search_page(cfg, get_param(req, 'q', ''))
case default
  resp = html_response(layout('<p>Page not found!</p>'), 404)
end select

URL and form-encoded POST variables are decoded for you; get_param returns a deferred-length string of any size:

query = get_param(req, 'q', '')

Pass values to a template as key/value pairs. They are HTML-escaped when inserted into #{placeholders}:

html = render_jade(row_template, [ &
  tvar('name', rows(i)%name), &
  tvar('latinName', rows(i)%latin_name)])
