The easiest way to serve files is to put them into the static directory.

For more dynamic and readable layouts, you can use an HTML templating system similar to Jade or HAML:

body
  h1 Hello World
  ul.className
    li#one Inside Text
    li#two Inside Text 2
    li
      a(href="http://example.com") Link

You can insert variable names into your template. Values are HTML-escaped, so data from the database or the URL cannot inject markup:

h4
  span #{name}
  small #{occupation}

Loops and conditionals live in the controller, which renders a template once per item:

call load_template('template/result.jade', row_template, ok, errmsg)
do i = 1, size(rows)
  html = html // render_jade(row_template, [ &
    tvar('name', rows(i)%name), &
    tvar('occupation', rows(i)%occupation)])
end do
