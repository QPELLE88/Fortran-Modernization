The easiest way to serve files is to put them into the static directory.

For more dynamic and readable layouts, use the Jade-style templates in template/:

body
  h1 Hello World
  ul.className
    li#one Inside Text
    li#two Inside Text 2
    li
      a(href="http://example.com") Link

You can insert variables into text and attribute values. Their values are HTML-escaped:

h4
  span #{name}
  small #{occupation}

Loops, conditionals and container divs belong in the controller, which also passes variables to the template engine:

type(string_map) :: vars

call vars%set('name', 'Nick')
call vars%set('occupation', params%get('job', 'mapmaker'))   ! ?job=... from the URL

call page%append('<div class="container">')
call render_template('template/profile.jade', vars, html, ok)
call page%append(html)
call page%append('</div>')
