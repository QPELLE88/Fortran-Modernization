The easiest way to serve files is to put them into the static directory.

For more dynamic and readable layouts, you can use an HTML templating system similar to Jade or HAML:

body
  h1 Hello World
  ul.className
    li#one Inside Text
    li#two(title="second", data-x='2') Inside Text 2
    li
      a.btn.btn-link(href="http://example.com") Link
    | plain text line

You can insert variables into your template. #{key} is HTML-escaped; !{key} inserts trusted, pre-rendered HTML as-is:

h4
  span #{name}
  small #{occupation}

Loops and conditionals live in the controller, which renders a template per item. Variables are passed as key_value_t pairs:

type(key_value_t) :: vars(2)
character(len=:), allocatable :: html
logical :: ok

vars(1)%key = 'name'
vars(1)%value = 'Nick'
vars(2)%key = 'occupation'
vars(2)%value = 'mapmaker'

if (get_param(req, 'lang') == 'english') then
  call jade_render_file('template/result-english.jade', html, ok, vars=vars)
else
  call jade_render_file('template/result-spanish.jade', html, ok, vars=vars)
end if
